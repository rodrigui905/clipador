# Política de privacidade do Clipador

Última atualização: 18 de outubro de 2026.

O Clipador é um aplicativo de uso pessoal que roda no computador do próprio usuário. Não existe servidor do Clipador e nenhum dado do usuário é enviado para os desenvolvedores.

## Dados do Google

O Clipador pede acesso ao YouTube (permissões youtube.upload e youtube.readonly) somente para enviar ao canal do próprio usuário os cortes que ele aprovou e para ler o nome do canal conectado. O token de acesso fica salvo apenas no computador do usuário. O Clipador não lê, não vende e não compartilha nenhum outro dado da conta Google.

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

## Vídeos e transcrições

Os vídeos baixados e os cortes gerados ficam no computador do usuário. Para escolher os melhores trechos, o texto transcrito do vídeo é enviado à API da Anthropic (Claude) com a chave de API do próprio usuário. Nada é guardado pelo Clipador fora do computador do usuário.

## Como revogar o acesso

O usuário pode remover o acesso do Clipador à conta Google a qualquer momento em https://myaccount.google.com/permissions
