# Clipador

O Clipador é um aplicativo de uso pessoal que roda no computador do próprio usuário. Ele transforma vídeos longos em cortes verticais curtos, com legenda, e agenda a publicação desses cortes no canal do YouTube do próprio usuário pela API oficial do YouTube.

Política de privacidade: https://rodrigui905.github.io/clipador/privacidade.html
